# Benchmark archive and reproduction

Each named JSON file retains measurements from the corresponding release or workload. The adjacent Python scripts reproduce specific comparisons; consult [BENCHMARKS.md](../BENCHMARKS.md) for methodology, versions and limitations.

Existing paths are preserved so historical links and reproduction commands continue to work. Record new runs separately rather than overwriting historical data. Use `tripol arena` for current measurements; do not treat old results as current-version performance.
