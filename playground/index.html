The interpreter runs an educational subset of TRIPOL: int64 integers, booleans, strings, functions, arrays, loops and basic scalar interpolation. It is not the native compiler. In the interpreter, imports, files, networking, graphics and other features are not available yet.
Web Engine uses TRIPOL parsing and validation to compile a TRIPOL subset to WASM. The generated file uses the TRIPOL console and arithmetic host ABI; it is not a standalone executable.
Sharing includes code in the link; never share passwords or tokens. Interpolation does not support nested fields or inner quotes.
Code runs in a local Worker with time, step, output and array allocation limits. It is not sent to a server.
