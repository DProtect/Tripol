R2 runs an educational subset of TRIPOL: int64 integers, booleans, strings, functions, arrays and loops. It is not the native compiler. Imports, files, networking, graphics and other features are not available yet.
Code runs in a local Worker with time, step, output and array allocation limits. It is not sent to a server.
