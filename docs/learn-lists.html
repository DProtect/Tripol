Lists

Use growable, homogeneous collections.

Create and grow a list

list() creates an empty integer list. list([values]) initializes a list from homogeneous scalar values. add appends an element and returns the new size.

numbers = list([10, 20, 30])
numbers.add(40)
show numbers
show numbers.get(3), len(numbers)
Expected output
[10, 20, 30, 40]
40 4

Read, update and remove

Use zero-based indexing, get, set and remove_at. remove_at returns the removed element. clear resets the logical length; size and capacity report current size and reserved capacity.

numbers = list([10, 20, 30])
numbers[0] += 5
show numbers.remove_at(1)
show numbers
Expected output
20
[15, 30]

Typed lists

Nonempty homogeneous initializers infer string, boolean or float lists as well. For empty typed lists, use string_list(), bool_list() or float_list(). Mixed element types are rejected.

names = list(["Ada", "Alex"])
names.add("Sam")
show names[2]
Expected output
Sam
Important

Lists are distinct from ints. Array-only library functions do not accept lists. Aliases share one list handle; integer, boolean and string lists have contains, remove and sort; float lists do not have these methods in R1.
