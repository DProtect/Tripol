Quick start

Install the Windows x64 distribution (unsigned) or the Linux x64 distribution from the download section. Open a new terminal after installation. You do not need Go, Python or GCC to use the distributed compiler.

Create a project

tripol --version
tripol new Hello
cd Hello
tripol run
tripol build

Edit main.tri in your preferred editor.

name = input("Your name? ")
show "Hello", name

Write a function

func greet(name="Guest", score=10)->string {
    return f"Hello {name}, your score is {score}"
}
show greet()
show greet("Alice", 25)

Explore the tools

Use tripol learn en for an offline tutorial, tripol libs to list libraries, tripol docs math to inspect source, and tripol check main.tri to validate a program. tripol run main.tri --trace adds call traces. tripol fix main.tri previews suggestions without editing files.

First 2D game (Windows x64, experimental)

tripol new MyGame --template game
cd MyGame
tripol run

Use WASD or arrow keys and Escape to quit. The renderer uses an RGB array and GDI. See the graphics guide.

Updates

tripol update --check
tripol update

Check or download an official release with SHA-256 verification. Install manually after closing TRIPOL. See UPDATE R1.
