Modules

Import standard libraries and create your own reusable modules.

Import a standard library

Place import statements before declarations and program instructions. Standard library imports use tripol.name; call functions with their module prefix.

import tripol.math

show math.square(7)
Expected output
49

Standard library catalog

Create a local library

Create two files in the same project directory. Local .tri modules can contain function definitions and imports, not top-level executable statements. Imported local functions share the top-level namespace and are called without a prefix.

helpers.tri

Native TRIPOL · local execution

func double(n:int)->int {
    return n * 2
}

main.tri

Native TRIPOL · local execution

import "helpers.tri"

show double(21)
Expected output
42

Native TRIPOL · local execution

tripol run main.tri
Important

Paths are relative to the importing file and must stay inside the project. Local module examples need real project files; the browser compiler does not provide them yet.

Package your code with Vault

Vault installs a local .tri library as a named package with a version and source hash in the lockfile. Use the helpers.tri file from the previous example and run these commands in the native project.

Native TRIPOL · local execution

tripol add helpers helpers.tri --version 1.0.0
tripol packages
tripol verify

main.tri

Native TRIPOL · local execution

import vault.helpers

show helpers.double(21)
Expected output
42
Important

Vault is local and has no public remote package registry. Only use trusted code; keep the lockfile and local package cache for reproducible offline builds.
