Learn TRIPOL

From your first line of code to reusable modules. Follow the 14 lessons in order, or jump to the topic you need.

Examples use the real TRIPOL syntax. Browser Try it runs the Web Engine; examples marked Native TRIPOL require the installed compiler. Expected outputs describe intended behavior, not a guarantee that every target has been tested.
