Arrays

Create, index, change and iterate integer arrays.

Fixed arrays

A literal like [10,20,30] creates a fixed integer array. Indexes begin at zero; len counts elements. Its length cannot grow.

a = [10, 20, 30]
show a[0], len(a)
a[1] += 5
show a
Expected output
10 3
[10, 25, 30]
Important

Accessing an index outside the array is an error.

Runtime-sized arrays

ints(n) creates an integer array of n zero-initialized elements. Its length is chosen at runtime but remains fixed. Assignment of dynamic arrays shares their backing reference.

a = ints(3)
for i in range(3) {
    a[i] = i * 2
}
show a, sum(a)
Expected output
[0, 2, 4] 6

Array utilities

Import arrays or collections for operations such as sum, copying and appending into a new array. Mutating library functions generally require a dynamic array.

import tripol.collections

a = [1, 2]
b = collections.append(a, 3)
show a
show b
Expected output
[1, 2]
[1, 2, 3]
Important

For a collection that grows in place through a handle, use list().
