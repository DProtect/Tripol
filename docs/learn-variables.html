LESSON 02 OF 14

Variables

Store values, update them and define constants.

Create a variable

A bare assignment creates a mutable local if it does not exist, or updates it if it does. TRIPOL infers the type from the assigned value. let explicitly declares a mutable binding.

score = 10
let bonus = 5
score = score + bonus
show score
Expected output
15

Update a value

Use = to replace a value and compound assignments such as += or -= to update it. A variable cannot change its type after declaration.

health = 100
health -= 20
health += 5
show health
Expected output
85

Constants and scope

const prevents reassignment of its binding. Names are ASCII identifiers; avoid shadowing. A constant reference is not a guarantee that all shared data are immutable.

const max_health = 100
health = 75
show health, max_health
Expected output
75 100
Important

Do not assign to max_health after its declaration.
