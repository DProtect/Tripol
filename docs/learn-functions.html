Functions

Create reusable code with parameters, returns and defaults.

Define and call a function

func declares a named function. Parameters receive arguments, -> specifies a return type, and return sends a value back. Declare functions before the program statements in these examples.

func add(a:int, b:int)->int {
    return a + b
}
show add(4, 5)
Expected output
9

Optional parameters

Trailing scalar parameters may have constant default values. Required parameters come first; omit optional arguments to use their defaults. Calls are positional.

func greet(name="Guest")->string {
    return "Hello " + name
}
show greet()
show greet("Ada")
Expected output
Hello Guest
Hello Ada

Short functions and inference

Use => for a single returning expression. Current TRIPOL can infer simple scalar signatures, but explicit annotations are useful for a stable contract. Functions have no globals or closures.

func twice(n:int)->int => n * 2
show twice(21)
Expected output
42
