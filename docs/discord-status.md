# TRIPOL v0.28 — DISCORD REVOLUTION

Estado de desarrollo frente al prompt maestro. «Completo» indica una capacidad delimitada con implementación y pruebas. «Experimental» indica una ruta implementada con validación local o con alcance reducido. Las pruebas TLS y Gateway usan un servidor local. Las pruebas reales de administración, mensajes y voz requieren un servidor privado autorizado.

## Medición local de SIMPLE R2

31 ejecuciones por compilador y caso con Linux x86-64, perfil `turbo` y `GOMAXPROCS=2`. La comparación cubre `2556c86` y el bloque SIMPLE R2 publicado en `d3a66ea`. Los tiempos de arranque incluyen el proceso. Los tres casos produjeron la misma salida. [Script reproducible](../benchmarks/simple_r2.py)

| Programa | Compilación mediana antes → después | Arranque mediano antes → después | ELF antes → después |
| --- | ---: | ---: | ---: |
| `bench_compiler_revolution.tri` | 3.764 → 4.001 ms | 0.387 → 0.348 ms | 1.422 → 1.422 B, idéntico |
| `academy/simple-r1.tri` | 2.917 → 2.828 ms | 0.439 → 0.468 ms | 2.294 → 2.294 B, idéntico |
| `discord_new.tri` | 18.202 → 19.225 ms | 0.313 → 0.320 ms | 30.267 → 30.702 B |
