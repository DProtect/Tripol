tripol.dictionary

Fixed-capacity string-to-integer map.

QUANTUM X 0.27.18 functions

Example

import tripol.dictionary

scores = dictionary.create()
assert dictionary.set(scores, "Alice", 100)
show dictionary.get(scores, "Alice")
Important notes

1..4096 slots, keys 1..32 bytes; linear scan. Avoid modifying backing storage directly.
