tripol.json

Bounded JSON serialization and raw-value parsing.

TRIPOL 0.2817 functions
Where to start

Start here: use quote(), pair() and integers() to create JSON; valid() to validate it; get_raw() to read top-level properties. The remaining scanner functions are advanced helpers. JSON values are returned as text, not general decoded objects.

Example

import tripol.json

data = json.pair("name", "Alice")
show json.valid(data)
show json.get_raw(data, "name")
Important notes

Raw lookup preserves quotes and escapes. Scanner helpers use byte offsets; bounded depth and input size. See implementation for parser contracts.

func quote(s:string) -> string {
    assert len(s)<=512, "JSON string limit 512 bytes"
    result="\""
    for i in range(len(s)) {
        b=byte_at(s,i)
        if b==34 {result+="\\\""}
        else if b==92 {result+="\\\\"}
        else if b<32 {result+="\\u00"+encoding.hex_byte(b)}
        else {result+=slice(s,i,i+1)}
    }
    return result+"\""
}

  b=byte_at(s,i); i+=1
  if b==34 {return i}
  if b<32 {return -1}

   if i>=n {return -1}

  }
 }

}

Decode into your own structures

json.decode(Type, text) supports homogeneous lists, text, signed integers and booleans. Missing or duplicate fields fail validation.

import tripol.json

struct Row {
    title:string
    values:list[int]
}

struct Report {
    ready:bool
    rows:list[Row]
}

report=json.decode(Report, "{\"ready\":true,\"rows\":[{\"title\":\"Temperatura\",\"values\":[20,21]}]}")
rows=report.rows
for row in rows {
    show row.title,row.values.get(0),row.values.get(1)
}
