tripol.ui

Experimental native Windows dialog helpers.

ASCENSION 0.247 functions

Example

import tripol.ui

ui.message("TRIPOL", "Hello!")
Important notes

Windows only; ANSI dialogs, ASCII recommended. Example opens a dialog.

func message(title:string, message:string)->bool {

 return ui_dialog(title,message,64)==1
