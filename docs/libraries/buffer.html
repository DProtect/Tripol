Documentation / 0.24

tripol.buffer

Growable integer backing arrays.

QUANTUM X 0.27.18 functions

Example

import tripol.buffer

items = buffer.create()
items = buffer.push(items, 42)
show buffer.values(items)
Important notes

Always reassign push. Capacity is at most 4,194,303. Growth can allocate a new array; old allocations are not automatically reclaimed.
