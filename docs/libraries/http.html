Getting started

Build a typed request or call a method helper.

http.request #

Build a request from a method and URL.

func http.request(method:string,url:string) -> Request
import tripol.http

r=http.request("GET","http://127.0.0.1:8765/health")
show r.method

Expected: GET

Runs offline. The example does not open a socket.

Responses

Read status and transport error separately. Text and JSON bodies share a 48 KiB byte limit and the launcher has a 65,535-byte response envelope.
