Error handling

Recover from selected failures with try, catch, finally and throw.

Catch an arithmetic error

On the native compiler, try runs protected code and catch receives the numeric error code if a recoverable failure occurs. Arithmetic errors use code 10; bounds errors use 11; failed assertions use 12.

Native TRIPOL · local execution

a = 10
b = 0
try {
    show a / b
} catch code {
    show code
}
Expected output
10

finally and throw

finally is optional and runs after success or recoverable unwinding. throw raises an application exception; use codes 100–255. Values outside that range normalize to 100.

Native TRIPOL · local execution

try {
    throw 101
} catch code {
    show code
} finally {
    show "Finished"
}
Expected output
101
Finished

Prevent errors

Check values before dangerous operations. The errors library offers fallback helpers that avoid selected arithmetic and parsing failures without using exceptions.

import tripol.errors

show errors.div_or(10, 0, -1)
show errors.int_or("abc", 7)
Expected output
-1
7
Important

try/catch/finally/throw are native features not yet supported by Web Engine R3. Native I/O, allocation and OS faults are not generally recoverable. return inside protected blocks is rejected.
