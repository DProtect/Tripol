# TRIPOL Language 0.24.0 for VS Code

Official editor support for `.tri` files: syntax highlighting, bracket and quote pairing, comments, and starter snippets. Covers all 48 standard-library module names. No language server, debugger or semantic completion yet.

Install `tripol-language-0.24.0.vsix` from a verified [release](https://github.com/Tripollas/Tripol/releases) when available, using **Extensions: Install from VSIX**. For development, open this folder and use the VS Code Extension Development Host. Marketplace publication requires a verified publisher account; the existing `tripol` publisher identifier is retained provisionally, not a claim of ownership.

Apache-2.0. Compiler installation is separate.
