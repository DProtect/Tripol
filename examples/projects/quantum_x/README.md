# QUANTUM X — Collect the light

Windows x86-64 software-framebuffer demo. Build with `tripol build examples/projects/quantum_x/main.tri -o quantum-x.exe`, then run. Space/click/XInput A starts; WASD/arrows/left analog stick move; M toggles optional short system tones (off initially); ESC closes. Collect golden lights in a scrolling tile map. Particle bursts, animated pickups, clipped scaled sprites, a camera, start menu and score bars are rendered without extra files. Reports frames, elapsed nanoseconds and average paced FPS on exit. FPS includes the 16 ms wait and optional synchronous audio, and is not a maximum throughput benchmark. Keyboard/mouse are game-focused; explicit XInput polling is not a background hook. See opengl.tri for the separate experimental native OpenGL triangle path with GDI fallback. Physical display, sound and gamepad behavior require manual validation.
