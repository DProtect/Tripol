# QUANTUM X — Collect the light

Windows x86-64 software-framebuffer demo. Build with `tripol build examples/projects/quantum_x/main.tri -o quantum-x.exe`, then run the executable. WASD/arrows move, ESC closes. Collect the golden square; the HUD bars track score. Reports elapsed time and frames on exit. No GPU acceleration, audio, gamepad, scene editor or menu in this first demo.
