# TRIPOL examples

- Start with `hello.tri`, `calculator.tri`, `dynamic_arrays.tri` and `modules.tri`.
- `projects/`: small practical programs, including expenses, notes and collections.
- `lib/` and `vault/`: module and local-package examples.
- `*_game.tri`, `form.tri` and `*_bot.tri`: platform-specific demos (see the graphics and Discord guides for restrictions).
- `bench_*.tri` and the adjacent Python comparison scripts: reproducible performance workloads. Their existing paths are preserved for Arena, benchmark scripts and historical documentation.

Compile an example from the repository root with `tripol build examples/hello.tri`.
